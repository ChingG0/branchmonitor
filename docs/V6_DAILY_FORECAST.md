# V6 逐日到期預報與同到期日修訂（包4、5）

正式方法版本 `v6-daily-deadline-baseline-1.0.0`，版本與協議雜湊見 `config/v6_distribution/daily-release.json`。本次只擴充期限、保存和呈現，不採用新的方向因子，不改 V6 冷卻0日／V6-2冷卻2日、65分或8%不追空規則。

## 讀法

每個收盤起點有 T+1、T+2、T+3 三列，均比較到期收盤與同一原起點收盤。上漲超過+0.5%、平盤包含±0.5%、下跌超過−0.5%。不是該日對前日報酬，也不能把三份邊際機率相乘當成路徑。以11/4為起點，期限是11/5、11/6、11/9（非11/8）。

每列顯示最新有效比例、最初比例、與前次有效保存值的變動百分點、期末中位與中央80%區間。展開可看所有保存、修訂、50/80/95%區間與樣本起迄。11/5收盤後對話更新：11/5核對實際結果，11/6剩1日，11/9剩2日；原起點和平盤界線不改。另開11/5起點為不同組。

到期後不再生成新機率；顯示最後保存比例及實際收盤、報酬和核對日期。延後核對仍用原到期收盤，不用較晚核對日價格。缺來源時新比例留空；舊值只在歷史中保留，不能假裝是本次新預報。

## 計算與研究界線

沿用共用T1等權長歷史基準，每次只取資訊日以前官方價格。先排除252日暖身，每個剩餘期限只取已完整成熟的1/2/3日歷史報酬，至少1260筆。以最新收盤乘歷史報酬倍數得到原固定到期日的期末價格分布，對原起點±0.5%分類，區間用反經驗CDF。T+3初始比例須與既有T1逐項相同。不加漂移、EWMA、分數或方向修正。

十月19起點、57初始／57修訂的離線回放已封存於 `research/v6_daily_horizons_20261104/`。新核心重現全部114筆，但回放不是未看過結果的保留樣本，更不是當時實際發布。初始方向判斷偏弱；晚期修訂已知更多價格，誤差下降不證明新增方向能力。正式頁標歷史基準，不標買賣訊號或勝率。原包6沒有通過的方向層不因介面上線而被放行。

## 保存與日期

只由對話主導的 V6 發布鏈建立初始值／修訂／結果，並原子保存到新comparison檔。GET、重整、前台更新與排程不產生逐日紀錄。沒有新增HTTP更新入口。舊快照不回填，不改原預報；每筆帶真正保存時間、來源檔雜湊、原起點檔雜湊、資訊截點和方法版本。

每個新起點保存當時已取得的官方交易日曆、快取取得時間及本次查核時間。臨時休市只依截點以前已保存日曆異動更正期限；同時保留原日期、有效日期、更動日期與來源。若只缺價格而沒有日曆依據，不推定休市，停止新比例。原公告時刻未保存時明示未知，不用查核時間冒充。

資訊截點不超過下一交易日08:30，下一交易日08:45起不補造盤前預報。提前或盤後保存僅列參考；08:30至開盤前的保存才符合該時點前瞻資格。新1/2日紀錄自真正啟用起累積；十月離線研究不移入正式資料。

## 成績與相容

同一起點若多次保存，先選首筆符合08:30資訊截點資格的根紀錄，否則首筆參考；保存所有其他版本但不重複灌入成績。完成期限按每個起點／期限唯一核對。RPS及Brier使用已保存機率；同根每個已經過天數的修訂採首筆合資格版本。頁面分開顯示各期限RPS及各剩餘期限修訂RPS，只對真正符合前瞻資格者計分，不把參考、回放與已知結果混入。不同期限互相重疊，樣本不能當作獨立試驗。

實際手動紀錄至少累積一個月再評估品質，期間不因看見輸贏改參數，未要求更新的日期不補造。初次啟用當晚尚無修訂或到期成績，正常顯示待累積。

新紀錄以逐日期限表為主，原三日期末圖和包8剩餘期間追蹤保留在可展開區。選舊快照仍呈現原版圖和保存規則；查看較早紀錄不會讀入未來修訂。V6/V6-2策略卡仍各自顯示分數、事件、部位與冷卻，兩者共用一份市場分布。
