# 融資觀察：單頁與分級

入口：側邊「融資維持率統計」。本次依使用者要求，將**觀察顯示**與**交易訊號採用驗收**分開。原包2門檻及研究封存保留；它們不再把主畫面的官方推導或有標示的估算一起鎖住。

## 主畫面

上市、上櫃各列三項：

1. 大盤融資維持率，標「官方推導」。公式為同日全部融資標的張數×1000×原始收盤加總，除以該市場官方融資金額；含ETF等商品，不依賴個股成本。
2. 個股低130%家數及融資金額，標「估算」，顯示平均成本／FIFO兩法範圍。缺市價或仍無成本的部位另列待分級，不鎖住其餘可估部位。
3. 官方融資金額及20交易日變化。

缺當日收盤的部位不補假價格。大盤維持率仍顯示可定價分子的推導下限，以「≥」及缺價數標明；全無有效價格就不顯示0%。這是融資部位市值／融資本金的推導，不是券商整戶真實擔保率。

## 個股與ETF

同頁選上市個股、上櫃個股、市值ETF、高股息ETF、正向槓桿ETF、反向ETF、其他商品或ETF全部（含主題與債券）。五格按距130%跌幅切分：已破130%、0～7%、7～13%、13～22%、>22%。

距130%跌幅=1−1.30÷維持率。130%恰好落入0～7%格；139.7849%、149.4253%、166.6667%是後三個精確分界，表頭140%、150%、166.7%僅為約數。每格顯示估算金額與占可分級本金比重；只有上市／上櫃個股列風險家數，ETF及其他商品不彙總家數。

兩法使用相同可分級部位池，再各自加總，顯示min/max。範圍不是信賴區間，也不是實際本金真實上下界；各格端點不能相加。兩法同一格只代表成本情境一致，不保證真實帳戶落在該格。

個股／ETF清單可搜尋、按融資金額／維持率／20日增加金額排序，並篩選任一算法低130%、跨級或待分級。

## 觀察用成本補估

沿用原平均成本／FIFO淨額庫存邏輯，另設觀察用成本延續版本，不改原交易研究引擎。缺成本單位優先沿用同檔已有單位借款代理成本；沒有歷史成本時，才以當時已可得的成交均價或收盤×一般成數作起始補估。舊本金不因後續股價變動整筆重估。

初始成本與補估保持假設標記，畫面另列含成本補估檔數及清單標記。不將補估認證為真實本金、不按官方總額配平、不推定未公開的部分還款金額。兩方法範圍未涵蓋所有初始價格、成數與公司行動假設的誤差。首次沒有任何可用價格或成本參考時仍保持缺漏。

## 四個子集

- 融資金額前30：以兩法估算本金中值排序，固定成員後比較兩法。
- 近20日融資增加金額前30：同檔20日前比較，以增加金額中值排序，只取正增加者。
- 20日RS前30：同市場、有融資普通股與同日RS名單交集後取前30。
- YTD贏過大盤：同日RS資料中的超額大盤報酬>0，且有融資。

上市／上櫃分開。列估算維持率、與同市場可分級個股全體差（百分點）、低130%融資金額、20日融資變化、5日維持率變化；點名稱可看成員。

線圖固定查閱日成員回看30個交易日，畫兩法中值，圖例顯示範圍與涵蓋；非當時已知名單的前瞻回測。資料不完整的點以空心表示，仍列可分級部位的估算；每日涵蓋改變可能影響線形，完全缺資料則不連線。變化按精確交易日及同檔可估部分比較，不拿其他日期或其他名單替代。

## 保存與讀取

- 明確建置：`.venv/bin/python -B -m backend.margin_observation_build`，不由GET或策略更新觸發。
- 唯讀：`GET /api/margin-statistics/risk?date=YYYY-MM-DD&category=listed_stock&market=TWSE`。
- 觀察資料：`data/margin_statistics/observations.sqlite3`。GET只彙整已存觀察，不下載、不重播成本、不更新帳戶。
- 本輪來源固定至2026-11-04；RS只用同日保存版，不用最新名單回填舊日。
- 本輪研究與證據：`research/margin_observations_20261105/`。保留未補估的初版於`without_cost_fill/`，原包2及第8包交付封存完全保留。

目前是風險觀察，不因此開啟清洗、背離或任何買賣訊號。V3、V6、V10、V11不由此頁更新。
