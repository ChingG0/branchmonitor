# Alpha／Beta 排行：分包與計算規格

2026-10-29 新增獨立研究頁，不改動既有策略及手動帳戶。

## 第一包：資料與計算

- 上市櫃普通股、ETF分組；同一組同一基準內排名，分開槓桿／反向ETF。
- 台灣基準使用證交所發行量加權股價報酬指數（MFI94U）與櫃買報酬指數（indexInfo/ROE），不使用價格指數代替。
- 個股／ETF在除息日以 `(當日收盤+現金股利)/前日收盤-1` 計算總報酬；核對官方除息前價。股息視為除息日再投入，未扣個人股利稅。除權、減資、面額變更、分割未逐筆還原者停止計分。缺價、停牌不前填。
- 海外基準只開放已核對的SPY、QQQ、DIA、SOXX含息ETF代理；按台灣交易日之前最新已收盤美國交易日，搭配同日美元／台幣匯率換算。台灣假日以整段level ratio累積；不機械平移一列。不匹配者明確顯示待核對。
- 固定版：60日評估窗開始前120個日報酬做含截距OLS，固定β及殘差波動。AR為個股含息報酬減β乘市場含息報酬，**不扣歷史截距**；故稱β調整累積超額，不宣稱傳統事件研究CAR。
- 殘差波動 `sqrt(SSE/(120-2))`；60日標準化分數為AR總和除以事前波動乘sqrt(60)。20日使用其自己事前120日估計窗。
- 滾動版每個評估日只使用前一日以前120筆資料；標準化分母為60個事前殘差變異數和開根號。
- 目前曝險β另外使用最新120個日報酬；HAC/Newey-West落後5日、有限樣本修正、常態近似95%區間。β變化比較60個交易日前120日β，將兩窗影響值放在共同180日軸估計差值HAC區間，考慮重疊。
- 週β以27個完整ISO週回歸作對照，不含未完成當週。
- 流動性門檻預先固定20日平均**實際成交金額**2,000萬元；殘差波動低於0.05%不排名。
- 延續型篩選：60日與20日累積超額均正、60日後半段超額正。固定／滾動排序比較採共同可計分樣本。

## 第二包：排行與前瞻驗證

- 顯示描述性排名與分數；不把排名前段、分數或R²解讀為顯著性、勝率或可直接買入。
- 每個版本、每個資料日保留第一次實際發布時間、當時股票池、分數排名、目前β、篩選狀態與輸入SHA256；再次更新不能改寫首次訊號。
- 首次發布後下一個交易日**收盤**作追蹤起點；後續20／60日到期才計算，不補填盤前訊號。
- 事先固定同商品組同基準的延續型前10%。固定與滾動版共用首次發布時的目前β衡量後續超額。
- 成本：雙邊各手續費14.25bp、滑價5bp；賣出稅股票30bp、ETF10bp。成本從組合經濟報酬扣除，rank IC不扣成本。為研究追蹤，非執行模擬。
- 缺價選股仍計入原分母、暫按現金處理，並標示部分結果及可定價數；不得將之視為完整績效。不同日期重疊的20／60日樣本不作獨立樣本推論。
- 目前沒有完整下市股票池及歷史資料版本，不能提供無存活者偏差的多年回測。當前資料由2026年開始，只進行前瞻驗證，不捏造歷史勝率。

## 第三包：介面與正式環境

- 側邊獨立頁、可沿用側邊手動排序。手機卡片、桌面表格，可搜尋、商品／市場／基準／計分版切換、排序、CSV匯出。
- 詳細頁展示計分β、目前β、HAC區間、R²、週β、估計／評估窗、固定與滾動走勢、流動性及公司事件限制。
- GET `/api/alpha-beta` 只讀已儲存結果。POST `/api/alpha-beta/refresh` 才取來源與產生排行，失敗保留上次完成結果。
- 納入一般「全部更新」，不觸發V3/V6/V10帳戶或研究決策。
- 獨立檔案在 `data/alpha_beta/`：raw附來源時間與雜湊、壓縮輸入、最新報告、不可覆寫的首次日訊號、獨立驗證結果。原策略prices表不被修改。

## 正式發布版本

`alpha-beta-v1.1` 為正式封存版本，另以輸入SHA256保留首次完整壓縮資料，可重現計算。功能建立期間的v1檢查紀錄原檔保留，不混入v1.1前瞻驗證。版本變更不回填過去的訊號或結果。

## 日α欄位

2026-10-29 補上可排序的「日α（120日估計）」、詳細頁與CSV欄位。直接使用既有最新120日含截距OLS的intercept乘100，以每日百分比顯示到小數三位；缺值不當0。不隨固定／滾動計分版切換。公式為平均個股含息日報酬減目前β乘平均基準含息日報酬，無風險日利率近似為0。這是歷史市場模型α，不等於60日累積超額、年化收益或未來預測。此次僅補充呈現，不變動計算、篩選、原排名與封存資料。

## v2.1：用途、區間與處置時點

2026-10-29起方法版本為 `alpha-beta-v2.1`；先前v1、v1.1首次封存檔保留，驗證結果不混合。

- 主表分成「強度排行｜參數事前固定・表現已實現」與「歷史描述｜最新120日事後估計」。滾動版第一組改標參數逐日估計。表現已實現指觀察到的歷史表現，不是事前預測；亦不代表實際平倉獲利。
- 60／20日欄名統一β調整超額，標明日報酬單純加總；不是複利。固定分數為超額日加總除以事前殘差日波動乘sqrt(60)，不是α t值。
- 最新120日α的標準誤使用同次回歸的HAC/Bartlett落後5日，有限樣本修正n/(n−2)。截距影響值為 `e/n − mean(x)*(x−mean(x))*e/Sxx`，不是直接使用事前殘差波動除sqrt(120)。區間為α±1.96×HAC標準誤，t比值為α／該標準誤。主表、明細與CSV均標示事後估計、每日%及未校正多重比較。
- 全組統計：在相同商品、基準、市場與處置政策的可排行池內，計算α區間不含0的正負檔數及有效N；全部α=0且邊際區間覆蓋率正確時，名目期望為0.05N。此數值不是實際錯誤發現數，亦不是顯著性檢定；股票相關性影響分布，篩選也可能改變區間覆蓋。統計不隨名稱搜尋或延續型篩選縮小。
- 基準預設依掛牌市場配對：上市對TAIEX TR，上櫃對TPEx TR，分市場排名。另可切換共同基準，全部商品用同一基準後跨市場比較。相關係數顯示四位小數、比較檔數與前10%重疊率；排名與比較均隨處置政策及市場更新。
- 圖表明列縱軸上界／下界（固定及滾動兩線共用、含0起點）與兩線各自期末值。
- 處置來源改為兩交易所可查詢的近期180日公告，保存URL、公告日、起訖日、查詢區間及實際取得時間。若資料未核對，狀態為未知，不把缺漏當成未處置。
- 以報告實際發布日為處置篩選日，另存價格收盤日是否在處置期間。例如10/28公告、10/29開始處置，10/29發布時即預設排除，即使行情仍為10/28。已結束處置不永久排除；未開始的公告醒目提示；未知狀態預設排除，可手動納入查看。
- 首次紀錄保存每檔當時的處置狀態、是否預設排除、原因、公告明細及觀測時點。各基準、市場、計分方法及處置政策的候選、名次與選中股票在發布時固定。驗證不查最新處置清單來改選舊名單。
- 每個版本的驗證結果另存在 `data/alpha_beta/validation/<版本>.json`，最新頁面只顯示本版本。每個資料日／版本的首次輸入依SHA256保存，原始首次日紀錄不可覆寫。
- CSV逐列包含方法版本、發布時間、資料日、基準模式、市場、處置政策、α區間、HAC標準誤／t比值及當時處置明細。
- 本階段未啟用日／週β差異警示及Dimson替代。日週β樣本高度相關，後續門檻不能直接假設兩個估計彼此獨立，需在同期間估計差值不確定性。

功能建立期間的v2.0資料檢查紀錄保留，不混入正式v2.1驗證。若任一市場處置來源未完整核對，顯示部分結果，該次不新增前瞻封存。櫃買的「本日無處置資料」空白列是提示列，不是缺漏的個股公告。
