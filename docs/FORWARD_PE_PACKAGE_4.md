## 每個歷史點從哪裡來

資料只讀包3 `data/forward_pe/calculations/<UUID>.json`已保存結果，逐份校驗SHA。GET不抓行情、EPS，不跑估值計算，不新增檔案或稽核，不發布策略、不加入首頁排程。

`GET /api/forward-pe/river`，可帶`as_of=<含時區時刻>`。只納入資訊截點及實際計算保存時間都不晚於as_of的結果；不是今天回建完就聲稱以前已發布。最新畫面按資訊截點排序，較晚重算的舊快照不會蓋掉較新的觀測。

一個月取資訊截點最後的已保存版本。該版本缺預估或資格不足就留缺口，不沿用同月較早的合格值。重複build不增加月樣本。日期按台北時區的資訊保存月，不把11/8才取得的EPS倒填成11/6已知估值。

「完整保存月」指該月所選版本50檔均合格；不是該月每日都有資料，也不是交易所月末價。每點保留股價日、成分生效日、資訊截點、實際計算保存時間、快照及報告ID。

## 歷史可比性與門檻

- 只採包3已通過資格的**完整50檔**倍數。包3的合格涵蓋子集也不混入河流，避免缺少公司改變比值。
- 來源／採集管道／幣別／基本每股與股數調整／均值或中位數／方法版本與規則SHA各自成系列。不跨來源拼接缺月。
- 年度以「當年年度」或「次年年度」分組，每點保留實際預估年度；年初年度變更斷線。其剩餘預估期間會變動，存在年度及季節口徑影響，不能稱NTM或當作固定期限預測。
- NTM只接受供應商明示起訖、接近當時未來12個月的來源（起點距觀測日不超過31天、長度330～400天）；不以年度加權製造。
- 各月依當時官方前50名單，成分會變動。這是前50方法的歷史，不是今天50家公司固定回推，也不是全大盤。

3年／5年基準分別取**當月之前連續36／60個合格保存月**，不把當月放進自身平均與樣本標準差。缺任何一月就不給位階。因此連同當期觀測至少需要37／61個月；不以每天重複保存充成月數。

五色界線為歷史均值的−1、−0.5、+0.5、+1個樣本標準差，依序為相對便宜、偏低、中間、偏高、相對昂貴。位階`z=(當期PE−前期均值)/前期樣本標準差`。百分位用先前樣本的經驗排序，平手算半個，不是上漲機率、常態分布涵蓋率或內在合理價。

河流每點的帶狀界線也只用該點以前的月份，未來資料不改過去；早期只有估值點但前置基準不夠時，只畫線，不畫色帶。缺月斷線，年度切換也斷線；不插值或補0。圖支援滑鼠、左右方向鍵及橫向捲動。
