## 保存與範圍

首次重算只用本機最新完整收盤與現有來源，另存 `data/v6_short_simulation/<實際時間-id>.json`，不重發新聞研究、不新增市場劇本、不改V3/V10/V11，不把歷史回放補登成當時的訊號或成交。只讀報表不重算、不抓來源，沒有新增HTTP更新入口。`/api/v6`也改讀同一份已保存主模擬，不再於GET臨時重算原V6。

`python -B -m backend.v6_short_simulation --publish` 是對話授權後的本機CLI，只重算主模擬。新一輪正常V6對話更新的 `v6_comparison.freeze()` 會在該份新比較快照內一併凍結 `short_simulation`，使用同一次已計算的V6-2交易，避免主卡與交易明細口徑不同。既有前台更新與排程不能觸發。

V6天氣頁讀取獨立主模擬與該次研究所屬comparison裡的主模擬，選較晚保存版本。明確選歷史研究時，只能讀到研究保存時間以前的獨立回放，或該份研究直接擁有的comparison；不向舊紀錄借用後來新增的版本。舊檔案不改寫。

## 解讀

本區為歷史模擬，起始空手，固定一口，不代表實際保證金可承擔的報酬。`signal`／`entry_allowed`固定空值，末日分數只描述最後資料列；是否新增空單仍看上方同日、來源齊備的V6-2人工研究卡。冷卻及8%仍須通過，不能直接把65分當成下單。

若本機僅到11/4，本次即只回放到11/4；不推定11/5行情，不假造當日預報。2025、2026已反覆研究過，勝率不是未來保證，也不是未碰過的樣本外驗證。
