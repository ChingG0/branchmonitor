# 預估本益比河流圖：包6整合與人工保存

包6補上EPS已保存前版變化、來源缺口與過期提示、前50清單／自訂族群CSV匯出，以及匯入新預估後的人工保存流程。沿用包3計算規則，沒有放寬資格，也沒有重新訓練或發布策略。

## 頁面

在localhost:3001的「預估本益比河流圖」：

- 左側EPS有已保存前版才顯示前值與差額。基本EPS及股數調整可比性未核對時，一律灰字「文件變化／口徑未核對」，不當作確認上修；新聞括號前值不倒填。NTM缺來源時不借年度EPS或年度變化。
- 「資料缺口與更新方式」可收折並記住狀態，列出當前口徑的缺預估股票、待核對原因、發布與入庫時間、報告／快照ID及更新步驟。
- 「匯出50檔 CSV」匯出所選期間／來源的完整50檔，不受搜尋影響。保留缺值、0及負EPS、資格原因、版本變化、來源ID／SHA、方法／規則、快照／報告、股價／權重／資訊日期。
- 類股完整清單的「匯出目前清單 CSV」跟隨當時選定日期、排序與篩選，保留來源、分類SHA、成交分母及限制；比重變化單位為百分點。
- 下載直接使用當時已顯示的回應，不能在匯出時偷偷換成另一份新資料。CSV含UTF-8 BOM及文字公式防護；數值負號保留。

「讀取最新保存」只讀取已存結果，**不是取得新資料**。開頁不輪詢、不自動重試，不發布V3／V6／V10／V11。估值來源壞掉時，類股仍獨立顯示，反之亦然。

`GET /api/forward-pe/dashboard`整合兩份唯讀回應，附讀取時間、最新已核對交易日及行情新舊狀態。新舊狀態以本機已核對交易日曆為限，不能當成已查過即時市場。估值行情落後、超前或最新交易日無法核對時，不顯示目前估值位階，保留歷史及來源提示。原有river／valuation／sectors API仍可使用。

## 人工更新順序

1. 先依使用者要求補齊市場資料中心的官方收盤與同日發行股數，以及需要的官方月底權重。
2. 將取得授權、可核對的EPS原檔加入`forward_pe_store add-source`，再用`import-eps`匯入CSV。欄位及範本見[包1、2](FORWARD_PE_PACKAGES_1_2.md)，每股／股數調整資格見[包3](FORWARD_PE_PACKAGE_3.md)。保留真正發布、預估與實際入庫時間。
3. 明確執行：

```bash
.venv/bin/python -B -m backend.forward_pe_refresh freeze
```

4. 頁面按「讀取最新保存」。有新合格來源才可能增加合格檔數；保存本身不會把缺值補齊。

`freeze`不連外下載，只用已保存來源。先取最新上市收盤日，要求該日50檔行情及股數齊全，核對官方來源身分及原始檔SHA；**不退用較早行情／股數共同日**。選該行情日可用的最新官方月底名單，納入50檔所有已入庫、已發布的EPS版本，讓計算引擎按來源／年度／口徑分組。

先匯入、後freeze可解決新CSV仍未進入舊明確快照的問題；原包3的舊快照仍只引用原本的ID，不能被之後匯入的資料改寫。新快照記錄真實資訊截點、獨立報告UUID與稽核；失敗不替換最新報告指標。這是單一人工寫入者流程，不新增首頁／18:00排程。

同月重複保存仍只有一個歷史月，河流只取當月最後資訊版本。完整50檔合格條件與先前36／60個連續月規則不變。
