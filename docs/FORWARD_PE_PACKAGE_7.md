# 預估本益比河流圖：包7首頁更新與整合驗收

依最初7包計畫完成首頁更新、缺漏提示、手機與收折檢查。前包已先完成類股與EPS差額，本包也補齊原定50檔清單排序及個股預估本益比欄。

## 更新入口

「今日市場資料中心」新增「預估本益比河流圖」，一般更新共20項。可按「更新全部資料」或該卡的「補齊此區」；既有每日18:00單次更新啟用時也走同一個流程。此模組排在融資維持率與景氣循環之後，先等上游保存好行情、股數，再處理估值。

首頁只使用**已入庫**行情、同日發行股數、官方月底名單及EPS版本。它不下載分析師共識、推估缺少的42檔EPS、授權登入或建立歷史共識。缺EPS、股數或月底名單時，明示在對話補齊。首頁卡完整換行顯示涵蓋與核對檔數，不把主要缺口截成省略號。

本頁「讀取最新保存」、所有GET及CSV下載仍只讀；不會重算或發布。`forward_pe_refresh freeze`仍可依對話明確保存。

## 單次工作與失敗保留

- `full_update._run_one('預估本益比河流圖')`只呼叫一次`forward_pe_refresh.update_home()`，成功或部分完成皆結束，不自行重試。
- 沿用每日只執行一次的排程；部分完成、失敗或重啟不會在同一天再次自動執行。人工按鈕才重試。
- 輸入指紋涵蓋台北評估日、成分版本、同日行情／股數及父來源SHA、當時可用的EPS版本ID、估值程式與規則SHA。
- **同一評估日、同一輸入、同一方法**不重算、不新增快照或報告。仍核對原始證據與已存報告SHA，卡片顯示「同日輸入未變，沿用原版」。跨日重新檢查預估時效，不因輸入沒變就永久沿用過期EPS。
- 來源身分、原檔SHA、同日50檔價格股數、最新已核對交易日或月底名單時效不符，保留上次報告及指標。缺股數不退到較早的行情共同日；過期名單不拿來當目前前50。
- 月底名單可用行情月或前一個月的官方月底版本；超過前一月即提示補齊。這是保守的月份時效檢查，**不是獨立查證交易所最新名單已公布**。
- 即使行情已更新，EPS不足仍顯示「部分完成」，不宣稱完整估值已可使用。完整50檔、同口徑36／60個連續月及非全大盤的標示不變。

所有原始資料、舊報告與策略帳本保留。首頁／排程皆不發布、核對或重估V3、V6、V10、V11，也不把本益比特徵自動加入策略。

## 清單與手機

50檔可按原月底權重、EPS文件值、預估本益比及同年度文件差額排序，缺值在最後，同值按原排名；負EPS不當缺值。年度切換仍分開，不把NTM借成年度資料。個股本益比可查，但口徑未通過者明示「未核對試算」；0／負EPS不顯示正本益比。

桌面左欄調寬，手機維持單欄、內部表格可捲動。資料缺口、試算及歷史的收折設定仍會在重新整理後保留。來源失敗也不鎖住獨立的自訂族群觀察。
