# 預估本益比河流圖：包3估值計算

包3完成個股與固定前50成分籃子的計算、來源資格／涵蓋率檢查、年度EPS版本比較、不可覆寫匯出及唯讀API。**正式估值仍受來源缺口限制**；本包不做河流圖介面或5年位階，不以今天的EPS重建過去。

## 計算口徑

個股：收盤 ÷ 同期間、同統計、同口徑預估EPS。EPS為0或負數時，個股本益比沒有可解釋的正值；仍保留EPS、帶正負號的盈餘殖利率及獲利貢獻。

籃子：**Σ（收盤 × 發行普通股股數）÷ Σ（預估基本EPS × 同一股數）**。這是公司層級EPS中位數的聚合結果，不是「整個指數共識分布的中位數」。不平均各股本益比、不直接加總各股EPS。虧損和0EPS均納入，總預估獲利不正時不輸出本益比。

聚合市值與獲利的原則可參照[MSCI基本資料方法](https://www.msci.com/indexes/documents/methodology/0_MSCI_Fundamental_Data_Methodology_20240625.pdf)；將公司盈虧一起納入可參照[NSE本益比說明](https://www.nseindia.com/static/products-services/indices-price-earnings-ratio)。本工具的自訂籃子不是任何一家官方指數的估值。

缺EPS時，只對有相應EPS的股票同時加總市值和獲利。不可用全50檔市值除以8檔獲利，也不外推缺少的42檔。月底權重涵蓋率和行情日重估市值涵蓋率各有自己的分母，不能混用。

- 成分：固定於2026-10-30官方市值排名前50，原始全大盤權重合計81.1679%。
- 行情／發行股數：同為2026-11-06，採未還原收盤、原始股數；不是自由流通權重。
- 資訊截點：2026-11-08 21:17:53 +08:00保存快照。有11/7發布的預估，不能聲稱這是11/6當時已知估值。
- 2026、2027年度分開；NTM只接受供應商明示起訖，不混成年份加權NTM。
- 共識供應商、採集管道、期間、均值／中位數、幣別、每股及股數調整口徑分組，不跨組加總。

## 資格與涵蓋門檻

固定規則在`config/forward_pe/calculation.json`，版本`forward-pe-valuation.v1`。包1、2的原規則保留。

可採用的每股獲利需為**basic基本EPS**，TWD、原始預估日期及調整證據齊全，並明確核對EPS股數調整日期與行情／發行股數日期。匯入範本增加`share_basis_date`。`diluted`須有稀釋股數才能聚合獲利，本包沒有該分母，不能默認乘普通股股數；`normalized`亦不混作基本EPS。這些或口徑未知的數字保留在未核對機械試算，不能當正式估值。

各組需同時符合：至少45檔、原月底籃子權重涵蓋至少95%、行情日籃子市值涵蓋至少95%、第一大權值股在內、50檔行情分母齊全、供應商預估日距資訊截點不超過45天、總獲利為正。從原始預估日計齡，不以今天下載冒充新預估。不信任資料列的舊`calculation_ready`旗標，計算時重新檢查。

門檻通過但未滿50檔時，只提供「通過門檻的已覆蓋子集」估值；50檔全部合格才有`exact_top50_pe`。兩者都不能稱全大盤預估本益比。

EPS版本變化只比較同組已保存前版，新聞括號前值不倒填。前值非正時只列EPS差額。若基本／股數調整口徑尚未驗證，標記`basis_comparability_verified=false`，變化也僅是試算，不能宣稱已確認上修。

## 保存與重算

```bash
.venv/bin/python -B -m backend.forward_pe_valuation build --snapshot-id 279fcb4f823f4e7a87fd9c2de131f2f1
.venv/bin/python -B -m backend.forward_pe_valuation read
```

只使用指定快照的行情及預估ID，不混入其後匯入的最新EPS。每次手動build產生新UUID的JSON及CSV，保留全部舊檔，追加稽核事件；`latest.json`僅是可替換索引。JSON含來源原檔SHA、來源網址與時間、快照SHA、計算程式SHA、規則版本／SHA、原始列與資格原因。保存前核對原始證據SHA，讀取時核對結果SHA。

`GET /api/forward-pe/valuation`讀最新已存結果；`?id=<32碼報告ID>`讀指定舊版。不下載、不重算、不建立空庫或更新策略，也不列入首頁／18:00排程。沒有已存結果時明示尚未保存。

測試包括總市值／總獲利、負值與0、缺值的配對分母、95%兩種分母、部分合格與完整50檔區分、最大權值股、跨來源／口徑隔離、舊報導晚到、已知時點、同版本衝突、當期股數調整、NTM期限、SHA、唯讀API與不可覆寫報告。包3新增16項測試，連同來源／資料層及既有河流圖共37項通過。
