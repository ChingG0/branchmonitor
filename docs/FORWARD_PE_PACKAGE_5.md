# 預估本益比河流圖：包5自訂類股漲跌

包5已在預估本益比分頁右側、前50籃子評價下方加入「類股漲跌」。直接使用我們原本的670個自訂多標籤族群，不拿交易所產業分類替代。此區不受預估EPS缺漏門檻封鎖，資料日期獨立列出。

## 可以查看

右側簡表可切換成交金額、漲幅、跌幅排序；簡表有自己的上下捲動。按「全部族群與前日比較」打開完整清單，可搜尋族群／大類、選大類、切換最近60個已保存收盤日期及篩選條件。長表格上下左右可捲動，手機有橫向滑動提示。點族群名稱會進入既有「族群流向」並定位該族群。

預設至少3個成員、兩日價格涵蓋至少80%，避免單檔或極少數股票主導排行；可切換全部670組（含小族群與缺價）。這是觀察顯示規則，沒有用歷史績效挑門檻。

完整表列：等權漲跌、漲／跌／平家數、官方成交金額、當日比重、前日比重、比重的百分點變化，以及價格／金額各自涵蓋檔數。金額顯示萬／億，百分比用%。

## 來源與算法

- 族群：唯讀`prototype/sectors.sqlite3`的`sector_groups`／`sector_members`及字典快照。分類SHA隨API傳回。現有分類快照為2026-09-11，670組；不是本次重建或改分類。
- 行情／成交金額：唯讀`data/margin_statistics/sources.sqlite3`內官方TWSE `MI_INDEX`、TPEX `dailyQuotes`已保存快照。API帶來源網址、取得時間、原檔SHA及快照ID。檢查快照市場／日期／種類與索引一致，並核對來源標示列數與實際列數相符。
- 交易日：唯讀主庫`market_days`核對前一個交易日，包含休市判斷。前日資料缺漏時，不拿另一個較早有價格的日子冒充前一交易日。
- 漲跌：同一股票、同一市場在所選日與前一交易日都有正的收盤價，才算`(今收／前收−1)×100`；族群取這些股票的算術平均，另列涵蓋率。是**等權未還原價格報酬**，除權息／分割會影響，不是官方產業指數，也不是市值加權。
- 成交金額：用來源的官方成交金額（元）直接加總，不用收盤乘量、不用成交值前幾名榜單代替。
- 比重分母：同日所有上市櫃**四碼股票**去重的成交金額，包含未分類股票；含四碼存託憑證，不含ETF、權證與六碼證券。不是含ETF的全商品交易額、前50檔成交額或所有族群金額的加總。
- 同一族群的重複成員去重；跨族群保留多標籤，所以族群比重不能相加，不把各族群正規化為合計100%。同代碼若跨市場重複則隔離排除，不任選一筆覆蓋。
- 當日／前日各自以其去重股票成交額作分母。差異為**百分點**，不是變動百分比；成交集中度不等於資金淨流入或淨買超。

群內金額不足時，只列已知部分及檔數。當日或前日的全市場分母缺漏，或該族群成員金額不齊，就不算相應比重；兩邊齊全才算百分點變化。0是有效成交金額，與缺值分開。缺收盤價不當作平盤；跨市場轉板不算同市場的日報酬。

歷史日期仍套用目前的自訂字典，並非當時成分還原；來源也是事後保存快照。這區不充作當時已知的歷史預測或策略特徵，不自動進入V6或每日跟單。

## 更新與API

`GET /api/forward-pe/sectors`讀最新已保存官方成交日；`?date=YYYY-MM-DD`讀指定保存日。每次開頁只讀一次，切日期或按「讀取最新保存」才再讀。該按鈕同時重新讀取估值及最新族群保存結果，不代表下載新市場資料。

GET不連外、不建立空庫、不改來源／族群字典、不重跑原型看板、不發布V3／V6／V10／V11。缺來源或金額有缺值時提示手動補齊市場資料中心，不自動重試。沒有新增EPS排程或修改原本首頁更新流程。

本包沒有新增市場來源檔或Drive同步；只讀Cloud工作資料，不能宣稱完成新雲端備份。程式碼與說明同步GitHub，來源資料不提交公開儲存庫。
