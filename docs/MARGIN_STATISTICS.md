# 融資維持率統計：包1

方法版本：`margin-statistics-sources-1`。品質規格：`MARGIN_STATISTICS_PROTOCOL.json`，在任何包2本金建模前固定。包1於2026-11-05建立，目標回補2023-11-01～2026-11-04（使用者於施工中改為近3年）。

## 已做範圍

新增獨立側欄「融資維持率統計」。GET `/api/margin-statistics`只讀取獨立資料庫，不觸發下載、成本模型或任何策略更新。頁面顯示實際涵蓋、回補進度、官方兩市場融資總金額、五籃初分、逐日流量／價格／發行股數與缺漏。原有側欄自訂排序保留，新項目自動補入。

沒有以融資餘額張數冒充融資本金，沒有顯示尚未驗收的個股維持率或分布，也沒有改動V1～V11的決策、成交或帳戶。五籃包括上市普通股、上櫃普通股、市值型ETF、高股息ETF、槓桿／反向ETF；其他與未確認商品保留獨立分類，不混入前三類ETF。槓桿與反向在之後計算前仍需分開方向及倍率。

## 保存與續接

獨立目錄`data/margin_statistics/`：

- `sources.sqlite3`：來源版本、各日最新版指標、逐檔融資、官方彙總、行情、發行股數、交易日曆及失敗紀錄。
- `raw/{sha256}.json.gz`：成功解析與驗證的原始回應；舊版本不可覆寫。原始回應相同則共用內容，來源日期與市場身分分開保存。
- `job.json`：有限回補作業進度；`backfill.lock`避免重複執行。
- `etf-reference.json`：當次ETF官方產品參考及出處，不等於歷史分類驗證。

原日今日餘額與次日可能修訂的前日餘額都在各自日報保存，包2不得先覆寫其中一個消除差異。同一日重新擷取若內容不同，新增版本並保留原值。讀取舊快取時若沒有原擷取時間，只能記錄本次觀察時間；該資訊不能作歷史即時可得性的證據。

回補命令（有限作業，非排程）：

```
.venv/bin/python -B -m backend.margin_statistics_sources --start 2023-11-01 --end 2026-11-04 --workers 6
```

可用同一命令續接未完成的日資料。主要來源已成功保存的日子不重抓；失敗日重試成功後移除失敗標記。官方回應非JSON、日期錯誤、欄位異常或不平衡皆不當零值。保留既有唯讀快取，但不改寫其檔案。回補不由GET、自動更新其他策略或排程觸發。若官方回應403／428／429，當輪停止該主機連線（包括尚未下載的日期），保留缺漏；不自動繞過防護或持續重試。頁面進度條為實際資料涵蓋率，不以處理完失敗任務視為完成。2GB可用空間下限會停止下載並保留進度。

## 包2開始前的阻擋條件

包1有來源不代表個股本金正確。包2須先處理逐日資料缺口、個股資格、ETF分類及公司事件，不可先跳到分布。總量每市場每方法每日±3%、60日漂移、兩方法敏感度、初始未知存量≤10%等門檻固定見JSON。總量吻合不能證明個股成本吻合。淨流量互抵是重建假設，須測試同日換手／舊部位替換敏感度，不能稱為投資人的真實批次。

包2後先完成2A十檔價格／兩種成本／融資餘額／未知存量檢查圖，再做分布與子集。包6／7採固定門檻的逐事件研究，前後各20日、鄰接觸發合併、未成熟標示；不回頭調整百分位，不宣稱少量事件的勝率。

這是市場融資部位的估計，不是券商整戶真實擔保維持率。130%只作統計參考。ETF除息、槓桿每日重設、反向方向及公司行動，都必須先處理才可以比較。
