# V11 手動 α 趨勢

使用者於2026-10-29要求把獨立α研究加入每日跟單，與V3、V6、V10一起在對話要求時更新。採研究中的 `alpha_t_trend`，不採原始α排序、不採β預算折減版。100萬元獨立模擬帳戶，建立時空手，不把研究回測獲利或研究持股當成已成交。

## 授權與更新順序

使用者要求更新V3、V6或既有V3/V6/V10組合時，也包含V11；明確限定只更新某模型則尊重指定。一般更新、排程、切日期、GET及前台重新整理皆不得核對V11成交、改估值或發布決策。沒有HTTP更新端點。

1. 完成所選日行情與官方含息基準、除權息、處置及實際成交金額核對；手動更新時可明確呼叫 `backend.alpha_beta.update()` 更新其官方原始輸入。確認 `data/alpha_beta/latest.json` 與 `inputs.json.gz` 日期及SHA256吻合，不用上一日α配今天價格。
2. 讀取 `.venv/bin/python -m backend.v11 report` 取得 `revision`。報告只讀已存快照，不計算策略、不寫檔。新建時為0。
3. 準備JSON：`{"expected_revision":0,"as_of":"2026-10-28","analysis":"說明本次所用完整收盤日、資料缺漏與市場條件；不把歷史α當成未來機率。","sources":[{"title":"台灣證券交易所","url":"https://www.twse.com.tw/"}]}`。
4. 執行 `.venv/bin/python -m backend.v11 publish --decision /absolute/path/decision.json`。預設只讀取已核對的Alpha原始輸入，不上網、不替其他模型發布。使用實際保存時間，不倒填盤前。
5. 逐項核對 `as_of`、`recorded_at`、`revision`、候選、`pending_orders`、持股、現金與淨值。四個手動模型分開保存，任一失敗個別報告，不宣稱全成功。

## 固定選股條件

與 `research/v11_alpha_20261029/registered-protocol.json` 的 `alpha_t_trend` 相同：上市櫃普通股共用加權含息基準，最近120日回歸的日α>0，按該次回歸自身HAC(5) t值排序。股價≥10元，近20日官方實際平均成交值≥2,000萬元、20筆完整觀察；完整120日含息報酬，殘差日波動≥0.05%。收盤>20MA、20MA>五日前、最近20日用當前120日β調整的超額>0、20MA乖離≤20%。此超額是訊號當時可得的歷史描述，不是固定事前參數的60日強度。

正式帳戶另外沿用Alpha頁的處置安全資格：發布日處置中或狀態未知者不新增，保存當次狀態與資料時間；不拿今天名單改寫過去。未核對除權／減資／分割的估計窗不產生α。

取前三名、最多持有三檔，不因持股在前三名而遞補第四名，不按排名變化強迫換股。加權與櫃買都低於20MA才停止新增。每筆預算≤淨值1/3與可用現金，股數≤訊號日成交股數1%，不借款。

## 手動計畫與執行時間

候選不等於持股。publish只建立後續買入計畫；必須晚於訊號收盤日，也必須是實際保存後尚未經過的開盤。台北09:00前保存可用當天開盤；09:00起保存不得回填當天開盤。只於下次手動publish核對既定計畫，在讀取或一般更新時不執行。

兩次對話之間不根據後來排名新增買單，不用事後資料更換原計畫。買入計畫只嘗試一次合格日期的開盤，缺價／鎖死／無空位則取消。新一次publish可取代仍未執行的舊計畫；舊計畫與快照不可覆寫。

已事前承諾的退出規則，於下次更新按每個已完成交易日核對：初始防線max(買價−3ATR14,買價×92%)，以先前收盤的最高點更新3ATR；達最高收盤+8%後永久轉2ATR，只升不降（除息另調整）。先處理開盤退出，再處理既定開盤買入，盤中退出款不回頭買同日開盤。可當日買入後觸及停損。跳空與無法成交可能使虧損超過8%。這和V3固定兩次更新間停損不同，必須在介面說明。

## 帳務與公司事件

買入成本0.2855%、賣出0.5855%。現金股息按除息日列應收，計入淨值與總損益，但在缺少發放日資料時暫不當現金再投資；相應調整既有停損／高點／成本參考，ATR仍用日K。非現金公司事件影響已持股時，整次publish失敗並保留上個快照，先補齊核對再繼續，不假裝已有可靠報酬。

帳戶只增量核對自己先前計畫，歷史價格修正不會重新選股或改寫舊快照。新快照保留完整輸入SHA與壓縮原檔；同時用預期revision與檔案鎖防止覆寫。純GET讀取 `data/v11_manual/`。

## 研究與正式帳戶分開

7/7起原始α排序未勝原V10；9/1起α＋趨勢表現較好，但只有3勝/7筆且非獨立樣本外。7月起趨勢研究遇未完整還原股票股利，不作有效績效比較。新手動帳戶不沿用任何有利研究起點或研究報酬。手動計畫的執行頻率也不同於每日規則回測，不能聲稱會重現+34.23%。
