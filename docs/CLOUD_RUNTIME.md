# 雲端資料、本機執行

使用者選擇GitHub clone程式＋Google Drive桌面版串流資料。本機瀏覽器仍連本機後端；網址不能用來判斷資料已在雲端。

固定地址：

- 原本本機版：`http://127.0.0.1:8765`，既有啟動／停止command保持預設。
- 獨立雲端版：`http://localhost:3001`。雲端資料初始化完成後，啟動／停止入口分別傳入`--port 3001 --browser-host localhost`。安裝Python依賴後重新啟動也必須保留參數。

啟動器會驗證health回傳的專案目錄；同一連接埠若是另一份Branch Monitor，拒絕誤開。停止器也只停止該目錄的程序。服務只綁127.0.0.1，不公開區網。
