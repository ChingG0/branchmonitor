# V6 夜盤、海外與近期波動評估

方法版本：`v6-live-context-1.0.0`，2026-11-06 起使用。僅使用者在對話要求更新 V6 時擷取及發布；重整頁面、前台更新和排程都不抓價、不產生新決策。這次只更新 V6，不連動其他手動帳戶。

## 時間與來源

- 台指期：期交所公開盤後行情 API，逐合約保留最新成交時間、來源原日期、同合約日盤收盤、結算參考價、高低點。跨午夜日期僅映射到已知日盤後15:00至次日05:00的實際夜盤，且不能晚於擷取時間；盤中超過15分鐘的資料不算新訊號。盤後最後30分鐘的最終成交可作最近已完成夜盤資料。
- 美股：Yahoo Finance 標普500、NASDAQ、費半、台積電ADR、VIX，保留來源商品代號、交易時段、報價時間、前收及擷取時間。盤中超過20分鐘排除；收盤附近資料可列最近已收盤。早於台股本次收盤的海外資料不再次當成新訊號。使用 `previousClose`，不能誤用5日查詢起點的 `chartPreviousClose`。
- 台股：已核對的官方完整日線計算近5日、近20日、再往前20日日均振幅；ATR14、20日日報酬標準差、固定λ=.94的近60筆平方報酬EWMA。日振幅=(高−低)/前收；ATR使用真實區間均值。週振幅及連續週K取同一收盤日已保存資料，未完成週必須標暫估。

各次原始JSON保存於 `data/v6_live_inputs/<實際時間-識別碼>/`，manifest帶網址、擷取時間、原檔SHA256及解析結果。保存時間在取價之後。HTTP限制或非JSON立即停止該來源，不繞過限制；來源失敗顯示缺項，不用缺值判定安全。

## 期現差比較

夜盤相對同合約日盤收盤、相對結算參考價是兩個不同比較，分列點數與百分比。日盤期現差以該日合約收盤減加權收盤；兩者為各自收盤，不能稱同步套利價差。夜盤對已收盤加權差距明示為非同步比較，不能直接當隔日現貨跌點或即時套利價差。夜盤變動/加權ATR14只作量級參考，期貨與現貨不同。

## 分工與判讀

畫面在逐日預報上方新增「本次夜盤與海外評估」，原歷史分布保留。當可用近月夜盤、標普500與台積電ADR同為負，標示「夜盤與海外同步偏弱」；同為正則為同步改善。其他項目逐項列證據與時間，缺漏或分歧明示待確認。此標籤是條件描述，不是經驗機率。

本輪不修改模型係數、65分門檻、8%跌深限制、交易規則或冷卻日；不把即時報價混入尚未完成的日線。現有二分類T+1/T+2/T+3百分比仍為長期歷史基準，沒有使用這批即時因素，頁面必須明示。未取得歷史即時版本並通過預先固定的時點外驗證前，不主觀把跌幅換成下跌機率。

盤中更新也可獨立保存情勢評估；若次一交易日已開盤，沿用原先預報並提示原因，不繞過08:45保護、不假裝重新發布盤前機率。主頁讀取所選人工研究的即時區塊，即使該次未產生新雙策略快照也可顯示，舊研究不能借新研究的即時值。

舊預報和原帳戶檔維持不變。來源原檔與本次新快照另存，選舊預報不可借用本次即時資料。
