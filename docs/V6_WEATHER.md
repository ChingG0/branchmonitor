2026-10-31起另保留原版65分與跨資產新版的雙策略比較、三日上漲／平盤／下跌劇本，見 [雙策略流程](V6_COMPARISON.md)。在對話更新V6時，先手動執行 `python -B -m backend.v6_comparison_sources --refresh`；既有正式人工發布會一併保存雙策略。頁面讀取和市場資料更新不會執行此流程。

V6 已移到左側獨立頁。它展示的是**最後一次人工研究時凍結的預報**，不因首頁、每日跟單、V9 或市場觀測更新而改寫。頁面沒有更新按鈕，後端也沒有 V6 網頁更新入口。原 65／70 分台指期純空模擬保留於每份預報內；這些分數和歷史相似日收跌率都不是已校準的股災機率。

使用者在對話說「更新 V6」時，研究人員先取得並核對截至當下可取得的數據，必要時從本機執行 `backend.v6_tx.refresh()`；接著查找最新新聞、核對發布與事件時間、保留來源連結，建立 UTF-8 JSON 草稿，最後執行：

```bash
python -m backend.v6_weather /private/tmp/v6-review.json
```

發布會將當時的 V6 模型、已保存的價量／融資資料、人工查核指標和新聞一起寫成新快照；舊快照不改動。頁面透過唯讀 `/api/v6-weather` 讀取，也可用 `?id=<報告 id>` 看先前版本。若模型或來源缺資料，報告應標為「資料不足」，不得推定缺值為安全，也不得聲稱機率已校準。

草稿欄位：`market_as_of`（YYYY-MM-DD）、`stage`（形成／增強／高風險／減弱／平穩／資料不足）、`summary`、`drivers`、`watch_next`、`weakening`、`indicators`、`news`。每項人工指標至少包含 `category,label,value,unit,as_of,source,url,reading`；新聞至少包含 `title,published_at,source,url,impact,direction`。指標分類為 `ownership,margin,valuation,futures,global,rotation,events`。請使用官方或可追溯的原始來源，將新聞影響寫為可檢驗的傳導假設，而非已確定的走勢。

集保持股分級為每週統計，融資與法人部位有公布時差；每個指標都保留實際資料日期。大盤乖離、融資與維持率的本機數值在發布當下複製進快照。新聞不由瀏覽器或首頁自動抓取。若來源不可用，保持空白或註明缺漏，不用舊日期冒充新資料。

美國暗池另列 `darkpool` 分類。對話更新 V6 時，人工核對 [SqueezeMetrics DIX 頁面](https://squeezemetrics.com/monitor/dix) 或其公開 CSV 的最新交易日期，保存 DIX、前次變化與 GEX（若可取得）；不由首頁定時擷取，也不使用需要帳號的 API key。DIX 是標普 500 成分股暗池 DPI 的金額加權指標，GEX 為選擇權市場造市避險義務估值；兩者是美股市場結構的背景資料，不能直接轉成台股跌幅或 V6 空單機率。

2026/10/27 休市後更新注意事項：先檢查 `prices` 的 TAIEX 開高低收，不只檢查收盤日期。若缺開高低，可用證交所 `indicesReport/MI_5MINS_HIST` 月報逐日核對，收盤價須與既有行情一致後才補欄，否則台指期更新會停在前一完整日。臨時颱風休市需另外核對交易所或券商正式公告，補到 `bt_calendars` 並保留來源；年度固定假期表不一定包含臨時休市。V6 更新台灣 ETF 時只接受已驗證的本地交易日，依台股已完成收盤截止，不能套用美股尚未收盤的截止日；海外來源仍依美國完整日規則。排除報價源在10/23休市日產生的重複價格，不修改舊預報檔。

## 風險視覺總覽

- `V6RiskVisual.vue` 只讀取所選預報及更早的保存紀錄，不發出更新請求。
- 泡泡為離散警戒分級：平穩、形成、高風險。大小不代表機率或倍數；資料不足顯示灰色，增強／減弱僅為方向描述，不推定絕對等級。
- 前次比較以保存時間排序；同一行情日明確標為研究修訂，缺資料到有資料不計為風險從零升高。
- 歷史收跌圖可切換 65／70 分門檻，以實際收跌數／樣本數計算比例，並顯示整體基準與 Wilson 95% 描述區間。樣本重疊可能破壞獨立假設，不將區間稱為已校準預測。
- 總經分類卡只表示有無觀測及資料日期，不推定利空強度、完整度或信心。
- 驗證：`node --test tests/v6_weather_visual.test.mjs`、`npm run build`；瀏覽器檢查歷史切換、門檻切換及窄版溢位。

## 10/1 起的歷史回溯

人工預報從 10/18 才開始保存，較早日期放在獨立的「歷史重算」區，不偽造或改寫原始預報時間。`data/v6_weather_retrospective.json` 由對話工作手動產生，API 只讀取；首頁更新不重算。

```bash
python -m backend.v6_weather_history --start 2026-10-01 --end 2026-10-16 --dix data/v6-dix-history.csv
```

日期是台灣當天盤前 08:30，使用前一台股交易日收盤與向後對齊的海外日資料。沿用 10/17 研究固定模型，模型參數訓練至 2022 年；模型／策略挑選曾看過後續歷史，不視為樣本外或前瞻驗證。歷史檔可能被來源修訂，無原始發布版本可核對，因此公布時間為原研究的對齊假設。缺評分來源不給分，不把資料不足當低風險。

DIX/GEX 與融資只作當日補充觀測，不聲稱已納入原評分。DIX 公開 CSV 沒有發布時間，只列前一美國交易日且最多回取 4 天；當時新聞、集保持股與夜盤逐時資料未補時會列缺項。模型分數圖與人工警戒泡泡分開，低於 65 分不代表安全。未來對話要求更新 V6 時，可手動重新產生此回溯檔延伸至已完成的最新交易日。

數字顯示統一由 `v6Format.ts` 處理：金額換算萬／億並保留原幣別；百分比用 `%`，變化的「百分點」保留原單位，避免混同相對變動率。指數點位不換成金額單位，模型分數仍用「分」。

## 已發生跌勢分級（與 V6 續跌訊號分開）

使用者自訂級距：收盤相對本機保存日線的週期高點回撤達 5% 為「迷你」、10% 為「小」、20% 為「中」、30% 為「大」。盤中最大回撤另列為「本輪曾達」，不可拿來冒充目前收盤級距。若週內高點到後續日期低點跌幅至少 5%、超過之前四個完整週的平均週內下跌幅度、且當週收盤低於開盤，也標示迷你。每天先按價格日期排序；日 K 同一天的高低先後無法確定，不推定當日先漲後跌。四週比較排除當週資料。

10/7 收盤到 10/15 收盤為 49,806.37 → 46,969.87 點，-2,836.50 點／-5.70%；10/12 當週高低點為 49,412.90 → 46,795.38 點，差 2,617.52 點／5.30%。兩者口徑不同。10/16 收盤相對本輪高點回撤 5.72%，因此本份資料標為迷你；前四週平均週高低差 2.83%，本週 5.30% 約為 1.87 倍。歷史價格逐日回溯 2020、2022 最大盤中回撤，事件或新聞只作旁證，不從價格單獨推論因果。

同一份人工凍結資料另計算振幅和週 K 節奏。**日振幅**＝（當日最高－最低）÷前一交易日收盤，顯示最近 20 個交易日平均、最近 5 日平均及再往前 20 日的平均。**週振幅**＝（該週最高－最低）÷前一完整週收盤，顯示當週和之前 4 個完整週的平均；這與上段「週高低差 ÷ 當週最高」口徑不同，畫面要分別標示。週 K 紅／綠以週收盤相對週開盤決定，收平歸為平 K；未到週五的週 K 為暫估，不納入連紅或連綠次數。少於 20／25 個日振幅或 4 個前週振幅時標為資料不足，不能當成 0。

三項節奏檢查為最近 5 日日振幅平均高於之前 20 日、當週是綠 K 且振幅高於前 4 週平均、已確認週 K 連綠至少 2 週。畫面同時列目前連紅或連綠週數和前一段相反顏色的週數；連紅至少 2 週時標示週線尚未確認續跌。0／1／2–3 項分別顯示「未見波幅持續擴張」／「波幅升高，待確認」／「跌勢波幅擴張」，未收週時週振幅與節奏判讀為暫估。這是觀察標籤，不改動 5／10／20／30% 已發生跌勢級距或 V6 空單模型分數，也不是下跌機率。10/16 的最近 20 日日均振幅為 1.39%，最近 5 日為 1.85%，之前 20 日為 1.24%；當週週振幅 5.31%，前 4 週平均 2.90%，已確認週 K 連綠 1 週、前段連紅 4 週，符合前兩項、合計 2／3 項。

這份「已發生跌勢」由對話研究手動保存到 `data/v6_crash_scale.json`；`/api/v6-weather` 只讀取，且舊預報不能讀到較晚日期的級距。首頁更新不改寫。下一次對話人工更新 V6 時，使用已完成的加權指數日線重建：

```bash
python -m backend.v6_crash_scale --as-of 2026-10-16 --window-start 2026-10-07 --window-end 2026-10-15
```

日期範例隨本次研究更新；10/7～10/15 的收盤比較可保留為歷史參考。級距與原 V6 的 65／70 分模型不可互換。若未來要預測「迷你升為小」機率，須先定義持有／觀測窗口並以獨立期間驗證，目前不顯示此機率。
