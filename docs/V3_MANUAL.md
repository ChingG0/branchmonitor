# V3 手動研究帳戶

使用者要求：10 萬元本金，只在對話明確要求「更新 V3 持股」時更新。不得把 V3 放進全部更新、排程、每日名單生成或 GET 的計算流程。這是獨立模擬帳戶，不能送出真實券商委託。

## 後續每次明確要求更新時

1. 讀取 `python -m backend.v3 report`，保留目前 revision、持股、已承諾防線、未執行計畫。
2. 讀取 `python -m backend.v3 context`，確認行情、RS 與分點為同日；缺少資料則不建立新買進計畫。查明市場趨勢、廣度與可用現金。
3. 只對準備納入的個股查閱當時可得的公司公告／營收／產業供需或報價。每個論點保存來源網址及發表日期，分開寫已知事實、推論與失效條件。不要編造公司 EPS、財測、運價或股癌當期看法。沒有確認的基本面只能列為待研究。
4. 參考研究候選，人工可以否決、保留現金、減少預算或提出既有部位賣出計畫。最多兩檔、單檔預算不超過帳戶淨值50%，初始防線加成本的風險預算不超過淨值4%。不因想達到勝率目標而藏掉虧損交易。分數不等於勝率。
5. 輸出具體 decision JSON，明確記錄 `expected_revision`、`as_of`、`analysis`、`target_exposure_pct`、`conclusion`、`sources`、`actions`。買單附上預算、理由、論點、失效條件；不得回填歷史決策。
6. 執行 `python -m backend.v3 review --decision /absolute/path/decision.json`。此操作會先核對先前承諾的下一交易日計畫與固定停損，再保存今日判斷及未來計畫。任何錯誤均不寫入帳戶。新版號或同日重複更新必須重新讀取 revision；不能覆蓋原紀錄。
7. 把持有、賣出、待買、現金、決策依據與資料時間告知使用者。若當天才提出買單，不能宣稱已在當天開盤成交。最早從指令提交日之後的下一交易日試算，後續需再次手動更新才能核對。
8. 台灣時間 07:00 後手動更新 V3 選股時，同次從相同決策與已確認收盤資料建立市場研究，連同持股決策一次寫入帳本；GET 與全部更新不觸發。研究記錄保存時間及資料截止日，沒有足夠指數收盤資料時顯示缺項，不沿用舊研究冒充同步結果。只要求市場研究時仍可獨立產生，不得改動持股或委託。

沒有使用者的明確更新要求時，只讀 `report`，不呼叫 `review` 或重新初始化。一般資料更新即使已到最新日，V3 持股、評價及防線仍停在上次保存日。

## 決策格式

```json
{
  "expected_revision": 0,
  "as_of": "2026-10-15",
  "analysis": "寫明當時市場、個股論點及證據限制。",
  "target_exposure_pct": 0,
  "conclusion": "暫時保留現金。",
  "sources": [{"title": "來源與日期", "url": "https://example.com"}],
  "actions": []
}
```

買單格式：`{"side":"buy","symbol":"2330","budget":40000,"reason":"買進理由","thesis":"可驗證論點","invalidation":"論點失效條件"}`。
賣單格式：`{"side":"sell","symbol":"2330","reason":"退出理由"}`，代表全數退出。每檔只接受一筆，不重複加碼。預算需由當時帳戶重新計算，不能沿用示例。

若要切換研究規則，先研究並版本化，說明理由與新舊績效，既有手動帳戶歷史不重播。初版以兩檔主流、分數80、3ATR／8%防線、+8%後2ATR追蹤與4%開高限制為基礎。

## 回測解讀

`backend/v3_validation.json` 是凍結的歷史研究，不是手動帳戶收益。初版用5–8月選型，再以9月起的新帳戶檢驗；後段未優於V1，完成交易僅2筆。全期69.2%勝率的95%區間約42.4%～87.3%，不代表已證實勝率穩定高於50%。先前模型曾接觸相同期間，這不是真正未接觸的樣本外。

每日規則回測與使用者不規律要求更新的結果不同。每3／5交易日才決策的敏感度在頁面列出；既定停損在模擬上持續有效，但防線不自動上移。現實中是否下停損單由使用者自行執行，本服務不會送單。

`research/v3_study.py` 與 `research/package_v3_validation.py` 可重現研究；來源使用本機 `monitor.sqlite3` 的唯讀快照。除權息、分點事後選樣、零股撮合與歷史資料修正的限制保留在報告中。6個V3變體完整列出，不只顯示勝者。

## 市場研究區

07:00 後執行 `backend.v3 review` 會把同步研究保存在同次帳本快照。V3 決策檔可附 `market_study` 物件，提供較詳細的 `analysis`、`buy_condition`、`stock_target_pct`、`bond_target_pct`、`bond_reason`、`sources`；研究日期與版號由帳本流程設定。未提供時依本次 V3 決策產生保守的收盤版研究，不推測美股收盤或日韓開盤。獨立市場研究檔仍可另外產生；新的手動同步研究優先顯示，避免舊研究冒充最新判斷。

只在使用者明確要求「產生 V3 市場研究」或「更新 V3 持股」時，整理當時已可得的資料並產生決策檔：

```json
{
  "expected_revision": 0,
  "as_of": "2026-10-15",
  "analysis": "依研究日當時資訊寫市場研究及可能失效條件。",
  "buy_condition": "任一市場收盤重新站上當日20MA，且RS／分點同日可用、候選分數合格並完成人工審核。",
  "stock_target_pct": 0,
  "bond_target_pct": 0,
  "bond_reason": "說明債券是否適合此短波模擬帳戶與利率、信用、匯率資料是否齊全。",
  "sources": [{"title": "來源與日期", "url": "https://example.com"}]
}
```

執行 `.venv/bin/python -m backend.v3_market_study generate --decision /absolute/path/study.json`。產生器只更新 `data/v3-market-study.json`，不讀寫 V3 持股帳本。`report`／GET 僅讀已保存的研究檔；首頁全部更新、每日名單及排程不產生新研究。研究日未更新或指數不足20筆收盤時，不把舊研究冒充今天，也不硬造位階。上方支撐壓力僅取近5／10／20／60日收盤與均線中，距研究日收盤10%以內的最近兩級；部分大盤歷史高低價缺漏，因此不聲稱為盤中高低。下一交易日站上20MA的收盤門檻＝最近19筆收盤均值，向上取至0.01點；下一次收盤後仍須重算。任一指數重站均線只是解除市場否決，不保證會買進個股。債券配置需獨立核對商品行情、利率／信用／匯率與現金使用期限，無資料不因市場下跌而自動加入。
