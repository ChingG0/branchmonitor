# V6 剩餘2日／1日：包8

方法：`v6-remaining-baseline-1.0.0`。這是與原三日分布分開保存的剩餘期間歷史基準，沒有加入方向訊號，不屬於包6已驗證的三日T1。原V6、V6-2及個股策略V8的選股／交易規則均不變。

## 讀法與更新

上方共用分布是每次人工更新產生的新一輪三日參考；「原預報追蹤」則追蹤先前預報，固定它的起點與原第3日，不把到期日再向後移三天。

只有使用者在對話要求更新V6時，既有 `backend.v6_comparison.publish()` 會在**同一份新快照**附加 `remaining_updates`。這利用原子保存與獨立id，不另改舊檔、不由排程或網頁觸發。尚無新三日方法真正保存紀錄時顯示等待；不把相似80日舊紀錄改造成新方法。

每天只以最新完整台股收盤更新，沿用新三日分布的來源核對與時間條件；來源不足就另存不可用狀態，不顯示新機率。已到期的官方價格核對不依賴外資資料是否齊全。到期核對也只在人工發布時保存，讀取頁面不重新產生。

## 算式

原起點C0、第三日T與±0.5%界線固定。已知更新收盤Cu，剩餘m為2或1：

- 用官方歷史所有已有252日暖機、且m日結果在更新日以前已完成的起點，至少1260筆。
- 每筆 `R_m = C[j+m]/C[j] − 1`，移至現價得到期末 `Cu × (1+R_m)`，再相對原C0分類上／平／下。
- 等權歷史比例，顯示百分比採最大餘數法加總100.0%；中位與中央50/80/95%區間皆取同一份期末樣本的反經驗CDF。
- 不比對K線、不分27格、不把每日方向機率相乘、不偷偷加入EWMA／分數方向增量。
- **只條件於已知價位與剩餘天數**，未估計前段漲跌與後段報酬的依存關係。若原起點100、第1日已跌至99，上漲門檻仍是100.5，不改成99.495。

途中回落事件也保留原C0的−2%：若已觀察到最低價觸及，標「已發生」，不包裝成100%的未來預測。若未觸及，將歷史m日最低價相對報酬移到Cu後計數，採 `(命中數+0.5)/(樣本數+1)`；原3日E1與剩餘期間基準不混為同一產品。

## 保存與核對

每次修訂包含根預報id與原檔SHA256、新保存快照id、原起點、原到期日、更新行情日、實際保存時間、資訊截點、官方價格與協議版本雜湊。原值及每次修訂可展開比較。

到期後另存實際第3日收盤分類、相對原起點報酬、三日最低價是否回落2%及原機率RPS；晚幾天核對也只用原到期日，不用核對當日價格替換。已核對的根預報不重複保存結果。

歷史畫面只能看所選保存時間以前的修訂與核對，不能從未來讀回結果。原預報符合08:30保存資格才計入前瞻資格組數；提前保存的參考另留紀錄。同一起點日只取首筆合格原預報計分，避免人工重複修訂灌大筆數；其餘保存紀錄仍保留。不同日起點依然重疊，不把組數或RPS當策略勝率。RPS按下／平／上順序，兩個累積機率平方誤差的平均，越低越好。
