# 包2A操作與資料口徑

入口：側邊「融資維持率統計」→「10檔個股 · 成本重建檢查」。

1. 選固定名單內的股票，並切換「淨變動」或「換手情境」。
2. 上圖比較收盤與平均法／FIFO等值成本；中圖是每日融資餘額（張）；下圖是未知存量占餘額比例。
3. 游標對準日期，四張讀數卡同步；移開回到最新日，若已用日期選單定位則回到定位日。可用「回到最新」取消定位。
4. 期間有30／90／239／全部交易日；圖表使用正常左右捲動。選股、模式與期間會保存在目前瀏覽器。
5. 灰色斜線表示缺融資來源，橘線表示模型起始／重設，10%線僅是單項參考。重設日可展開並點選定位。

等值成本＝包2診斷本金÷餘額張數÷1000÷0.60，使用六成假設；並非實際買入均價。未知存量低或兩條成本線接近，均不表示模型已通過。上市5檔目前只有2日，上櫃5檔有729日，缺口保留。

API：唯讀GET /api/margin-statistics/checker，可用symbol選固定10檔之一。讀取頁面不會重算或下載來源。封存資料位於data/margin_statistics/checker.json.gz，由backend.margin_checker明確建置；其建置須驗證包2固定輸入、方法及名單摘要。這不是前台更新功能，也不更新交易策略。
