# 景氣循環分析

側欄「景氣循環分析」，在「市場觀測」後。提供台灣景氣對策信號、季調製造業PMI、CPI年增率、外銷訂單年增率，以及美國S&P Global製造業PMI與CPI年增率。圖表按實際月份顯示，缺月斷線，可切近1／3／10年或全部；最新卡片列前月差異、來源、資料月、發布與取得時間。

- 國發會官方網頁工作階段與防偽驗證後，讀取`/n/json/lightscore`及`/n/json/PMI`；目前分別提供近12、2月，後續累積，未捏造長歷史。
- 主計總處`Point.aspx`的`hidChartData`為JSON，安全解析而不執行網頁腳本。CPI只取月資料，排除同名年度預測。外銷訂單保留百萬美元原金額，以同月去年金額算年增率，不以12列前代替12月前。
- 美國CPI讀BLS的`CUUR0000SA0`未季調總指數，取得近4年、計算可配對月份的年增率並四捨五入至1位小數。M13年平均排除，`-`、`.`缺值保留為缺月，不填值；2025年10月有官方缺值。
- 美國PMI的公開網站限制程式讀取。初始依2026-11-02 S&P Global官方評論核對9月55.9、10月54.9終值，存`data/business_cycle/manual/us_pmi.json`並帶真正查核時間、原始URL及發布日期。前台顯示「官方查核保存」及手動補齊提示，不把10月快報56.0混成終值。後續新發布須在對話查核補入；不聲稱自動來源已齊。
- 景氣燈號9–16藍、17–22黃藍、23–31綠、32–37黃紅、38–45紅。紅燈表示熱絡，非股市賣出訊號。PMI相對50及前月變化描述擴張／收縮的速度，不構成預測模型。美國CPI不是Fed的PCE目標。

## 取得與更新

`GET /api/business-cycle`僅讀`data/business_cycle/latest.json`。`POST /api/business-cycle/refresh`啟動一次有限更新，並行按鈕重複請求共用鎖。`python -B -m backend.business_cycle`可執行一次同步更新。原始回應以SHA256存於`data/business_cycle/raw/*.gz`；取得時間不是原始發布時間，介面未提供時明示缺漏。歷史為最新修訂值，不能無條件當成當時可用版本回測。

首頁全部更新與每日18:00單次排程包含此模組。來源失敗保留既有資料與原取得時間，狀態為部分完成、提示手動補齊；不自動重試。首頁狀態按已保存月份及來源缺漏說明，不把月資料當每天都應產生一筆。不觸發V3／V6／V10／V11發布或調參。

資料在雲端版獨立工作快取。新增資料完成不等於Drive已讀回驗證同步；目前未因新增分頁執行全量雲端重傳。程式碼與資料分開保存。
