# 歷年月漲幅前三名：自訂族群

方法版本：`own-sector-month-leaders-1`。首次回補：2026-11-05。

## 畫面

「月份漲跌統計 → 歷年月份漲跌」的台股每月百分比下方，以括號小字列出月漲幅最高的三個上漲族群。滑到名稱可看漲幅、使用成員檔數、族群總檔數及日期。本月標示「暫」，只算至該格台股收盤日期。S&P 500與全年報酬格不附台股族群。

僅有一或兩個上漲族群時列實際數量；全部未上漲時顯示「無上漲族群」；不足以計算時顯示「族群資料不足」；與指數起訖日不同時顯示「族群資料待更新」。不將下跌族群標成領漲。

## 自有分類與算法

- 使用既有族群頁的 `backend.sector_flow.classification()`，來源 `prototype/sectors.sqlite3`，分類快照2026-09-11。
- 670族群、6,709筆成員連結、1,984個不同股票代碼。保留原本可重疊的分類；同一股票可以出現在不同族群。
- 個股月價格報酬 = （當月底收盤／前月底收盤 − 1）×100%。族群漲幅 = 可用成員個股月價格報酬的等權算術平均。沿用族群頁的端點報酬平均定義，不以20日報酬替代月份，也不是每日族群平均再複利。
- 每族群至少2檔，且有兩端有效價格的成員必須達目前族群成員的80%。未達門檻不參加排名。門檻固定，不隨月份績效調整。
- 按族群漲幅由高至低列最多三個正報酬族群；同值以名稱固定排序。

## 長歷史來源與範圍

1,970檔可對應台灣市場公開行情代碼，其中1,968檔取得Yahoo Finance月收盤歷史；2867與5371無可用公開回覆，另14個特殊代碼無可靠對應，保留在成員分母並記錄缺值。原始回應與來源清單存於 `data/monthly_statistics/sector-raw/`、`sector-source-manifest.json`、`sector-unmapped.json`。

原始股票月資料最早1993-01，但在固定成員數與涵蓋率門檻下，首次有族群可計算的是2000-02。本次共322個月有可計算族群，至2026-11本月暫排行，該格截至2026-11-04。更早的台股月漲跌數值照常顯示，族群部分不補造名次。不同年月可計算的族群數不同，提示內有涵蓋數。

已結束月份採Yahoo月線的 `quote.close`，不是 `adjclose`、月均價或現金股利總報酬。資料商歷史價格可能做拆併股調整，因此不宣稱是當年未經修訂的逐筆價格。時間戳是月份標籤，不能當成月底交易日。

本次匯入明確排除2026-11以後的Yahoo月線，避免API額外回傳當月即時值。進行中的月份一律使用與台股格子相同的兩個本機收盤日期；歷史Yahoo端點缺少時，只有本機也具備相同兩端日期才可補用。不以前向補值跨過缺月。本月只到11/4，不納入11/5盤中或收盤。

## 解讀限制

**這是依目前分類及目前成員回看的月漲幅排名，並非歷史當時的族群成員名單。** 舊年度可能出現當年尚未流行的主題名稱；現行股票池也不包含所有後來下市股票，存在存活者偏差。此功能不適合當作當時可交易的策略回測。

族群彼此可重疊；排名不是對加權指數漲跌的貢獻，也不代表下一個月會繼續上漲。等權平均不同於市值加權產業指數。

## 更新與維護

GET `/api/monthly-statistics` 只讀已保存的排名，不下載個股、不產生策略決策。前台「更新月份資料」完成指數更新後，會用現有長歷史快取及本機同日個股端點重算族群，失敗則保留舊排名並顯示來源錯誤。長歷史全量下載是本次明確回補操作，不會在每次開頁重新下載約2,000檔。

分類變動或資料商修訂需要重新匯入長歷史時，使用模組的 `import_raw()`，保存原始回應、代碼對應、匯入時間及來源清單，再 `refresh_sync()`；不得用尚未結束月份的月線替代本機端點。

## 2026-11-05：新增YTD切換

表格上方可切換「當月漲幅」與「年初至今（YTD）」，選擇保存在此瀏覽器，重新整理仍維持。切換只改小字族群排行；格內指數百分比、熱度色彩及下方逐月統計仍為原本當月漲跌。

YTD個股漲幅 = （各月底收盤／前一年最後交易日收盤 − 1）×100%，族群取可用成員的等權平均，重新套用至少2檔及80%涵蓋門檻。不是把每月族群平均直接加總，也不是拿全年最終贏家填入前幾個月。每年1月與當月排行相同；之後月份可以不同。前一年底沒有價格的成員不參加該年YTD計算，因此新上市股可能能算當月、不能算YTD。

歷史已結束月份使用同一份月線的前一年12月與目標月端點。本月YTD使用本機前一年最後交易日與當前格子日期的兩端價格，不混用調整基準不同的價格。缺前一年底價格時保持缺值；不借用下一年度或未來月份。本月仍標「暫」。各月YTD有自己的基準日、涵蓋數及來源記錄，存於 `sector-leaders.json` 各月的 `ytd`；API為 `sector_ytd`。GET仍只讀。

沿用目前分類回看及存活者偏差限制。詳細本次驗證見 `research/monthly_sector_ytd_20261105/`。

YTD首次可計算2001-01至2026-11，共311個月；原單月排名719個月份逐筆一致。27項後端測試、21項前端測試與正式編譯通過；JavaScript另以端點差值公式獨立驗算719個月份的YTD排名，未發現差異。桌面／手機切換、選擇保存、日期提示、百分比與顏色不變皆已驗證。
